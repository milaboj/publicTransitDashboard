Project Overview

This project explores public transit accessibility in Seattle by visualizing bus routes, light rail, transit stops, and walking access buffers. The goal is to better understand how transit availability varies across neighborhoods and how walkability affects access. The Seattle Public Transit Accessibility Dashboard explores how accessible public transportation is across Seattle neighborhoods. Using datasets from Seattle City GIS and King County Metro, the dashboard visualizes bus stops, light rail stations, and transit routes to help users understand how close different communities are to reliable transit. Interactive layers, buffer zones, and charts allow users to explore walkable access to transit and compare accessibility between neighborhoods. Our goal is to highlight patterns of transit connectivity and encourage conversations about mobility, equity, and urban planning. By making transit data easier to explore, this dashboard helps commuters, residents, and policymakers better understand how transportation infrastructure shapes everyday movement in Seattle.

Data Sources

Lightrail: The light rail dataset represents the link light rail stations located throughout Seattle. This dataset includes station names and geographic coordinates, allowing each station to be mapped and analyzed with the dashboard. The key fields in the dataset include the station’s name, operational status, station type, and geographic coordinates (X and Y). These attributes help identify active stations and distinguish them as part of Seattle’s high-capacity transit system. The coordinate fields were used to plot station locations on the Mapbox map, while the station name and status are displayed in interactive pop-ups. The stations also serve as anchor points for generating walking distance buffers that illustrate which neighborhoods fall within accessible distance of light rail service.

Transit stop: The transit stop dataset represents King County Metro bus stops located throughout Seattle. This dataset includes stop identifiers, street location information, and geographic coordinates, so each stop can be mapped and analyzed within our dashboard. The key fields in this dataset are the stop ID, service status, bike rack availability, accessibility designation, route list, and geographic coordinates (X and Y). These columns help to identify active transit stops as well as provide information about the amenities and services available at each stop location. The coordinate fields were used to plot the bus stop locations on the map, while the stop name, route list, and accessibility attributes are used to display information through interactive pop-ups for users exploring our dashboard. The dataset was cleaned to include only active stops within the Seattle jurisdiction, and unnecessary maintenance fields were removed to focus the information presented on what is important. These stops also are the center point for the walkability buffers that illustrate which areas are within convenient walking distance of public transportation.

How to Use the Map

Use the dashboard controls to toggle transit layers and walking buffers on and off. Comparing different walk times helps illustrate accessibility gaps and areas where transit access may be limited.

Why This Matters

Access to reliable public transit is a key equity issue. By visualizing walkable access to transit, this project highlights spatial differences that can inform transportation planning and policy decisions.
