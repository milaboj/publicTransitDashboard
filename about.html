Project Overview

The Seattle Public Transit Accessibility Dashboard explores how accessible public transportation is across Seattle neighborhoods. Using datasets from Seattle City GIS and King County Metro, the dashboard visualizes bus stops and light rail stations to help users understand how close different communities are to reliable transit. Interactive layers, buffer zones, and charts allow users to explore walkable access to transit and compare accessibility between areas. Our goal is to highlight patterns of transit connectivity and encourage conversations about mobility, equity, and urban planning. By making transit data easier to explore, this dashboard helps commuters, residents, and policymakers better understand how transportation infrastructure shapes everyday movement in Seattle.

Data Sources

The Link Light Rail Stations dataset from the City of Seattle Open Data Portal provides the locations of Link light rail stations across Seattle, including station names and geographic coordinates. These stations represent key components of Seattle’s high-capacity transit system and serve as important transit hubs connecting neighborhoods across the city. The geographic coordinates allow each station to be mapped within the dashboard and displayed with interactive pop-ups. The dataset can be accessed here.

The King County Metro Bus Stops dataset contains point locations for bus stops across King County, including attributes such as stop ID, service status, accessibility features, and route information. For this project, the dataset was cleaned to include only active bus stops within the Seattle jurisdiction. Unnecessary maintenance and database fields were removed to simplify the dataset and improve performance in the web map. The dataset can be accessed here.

The Seattle Neighborhoods dataset from Seattle City GIS provides the geographic boundaries of neighborhoods within Seattle. These boundaries allow the dashboard to compare transit accessibility between different parts of the city and help contextualize how transit infrastructure is distributed across neighborhoods. The dataset can be accessed here.

Together, these datasets allow the dashboard to map transit infrastructure, generate walkability buffers around transit stops and stations, and explore how accessible public transportation is across Seattle neighborhoods.

Methods and Analysis

Transit stop locations serve as anchor points for analyzing accessibility across Seattle neighborhoods. Using these locations, walking distance buffers were generated to represent approximate access to public transit stops. These buffers illustrate which areas fall within convenient walking distance of transit infrastructure.

Spatial analysis tools were used to prepare and analyze the data, including:

  • filtering stops to include only active locations within Seattle
  • cleaning the dataset by removing unnecessary attributes
  • generating walkability buffers around transit stops
  • visualizing accessibility patterns across Seattle neighborhoods


Interactive map layers, charts, and pop-ups allow users to explore transit access throughout the city and better understand how transportation infrastructure is distributed.

Tools and Technologiess

This project was created using a combination of GIS and web mapping tools, including:

  • ArcGIS Pro for spatial data cleaning and analysis.
  • Seattle City GIS and King County GIS Open Data for transit datasets.
  • Mapbox for interactive web map visualization.
  • Visual Studio Code (VS Code) was used to develop and edit the website code that powers the dashboard and integrates the interactive map.
These tools were used to transform raw data into an interactive dashboard that communicates patterns of transit accessibility across Seattle.
